# Notewell: frontend

Vite + React + TypeScript + Tailwind CSS v4. See the [project root README](../README.md) for
full setup, architecture, and how the frontend talks to the three backend API servers.

## Local dev

```bash
npm install
npm run dev
```

Requires `VITE_GOOGLE_CLIENT_ID` in `.env.local`. See the root README's setup section.
